Model assumptions
  • Wafer: 300 mm, 3 mm edge exclusion. A die counts only if it lies fully inside the usable area. Scribe lines are ignored.
  • Dies: cores sit on an 8×8 grid. Chiplets cut that grid into 8×4 (32 cores), 4×4 (16), 4×2 (8) or 2×2 (4) blocks. Each chiplet adds the interface (PHY) area for its interposer links.
  • Yield: Poisson model, Y = exp(−A·D₀). Defects on the wafer pictures are scattered uniformly, so the counts on screen vary around this expected value.
  • Cost per system: (n · wafer cost / (dies per wafer · Y) + interposer/package) / bond yieldⁿ, where n = 64 / cores per chiplet. Chiplets are tested before assembly (known good die), so only bonding failures waste good silicon. The result is normalized to the monolithic die.
  • Speed binning: each core's maximum clock is μ − slowdown · (r/R)² + σ · N(0,1), where r is the core's distance from the wafer center. A die runs at the speed of its slowest core, and a system runs at the speed of its slowest chiplet. "Sorted" ranks good chiplets by speed and groups neighbors; "unsorted" groups them at random.
  • Latency: uniform random traffic over all 64×63 source–destination pairs with XY routing. Latency = fixed cycles + hops × cycles per hop + chiplet crossings × crossing penalty. It is normalized to the most fragmented design.
  • Default values are chosen so the curves resemble the slides (Kannan, Enright Jerger and Loh, MICRO 2015). They are illustrative, not data for any real product.
